# ESP32 Development Board
Custom ESP32 development board designed and routed in KiCad, including schematic design, component footprint assignment, PCB layout, routing and 3D visualization.

## Project Status
Completed

## Overview
This project is a custom ESP32 development board based on the ESP32-WROOM module.
The board was designed from the schematic stage through PCB layout and routing, including power regulation, USB-to-UART communication, boot/reset controls, GPIO headers, and supporting components.

## Tools Used
- KiCad
- PCB Editor
- Schematic Editor
- 3D Viewer

## Board Features
- ESP32-WROOM module
- USB-to-UART interface
- 5V to 3.3V voltage regulation
- Boot and reset controls
- GPIO headers
- Status LED
- Two-layer PCB
- Ground copper zones

## Design Process
- Studied the reference ESP32 board circuitry
- Converted the reference into hierarchical KiCad sheets
- Assigned footprints
- Designed component placement independently
- Routed the PCB manually
- Added vias and layer changes where required
- Checked the design with ERC/DRC
- Corrected connectivity and layout issues
